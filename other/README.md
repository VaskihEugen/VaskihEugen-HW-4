# Вступ до Node.js

### Завдання

Налаштуйте проєкт на Node.js, який можна запускати за допомогою скрипта `npm start`. Додаток має читати аргумент командного рядка під назвою `--name`. Якщо цей аргумент відсутній у командному рядку, значення `NAME` повинно бути взяте з файлу `.env`. Якщо такого файлу немає, тоді ім'я (`name`) має бути встановлено як `"unknown user"`. Додаток має вивести повідомлення в консоль з текстом `"Hello ${name}!"`.

### Як протестувати

Перейменуйте [`.env.example`](.env.example) у .env або створіть власний файл для тестування.
Якщо ви хочете запустити тести локально, виконайте команду `npm install jest -D` для встановлення залежностей, після цього виконайте команду `npx jest` для запуску тестів.
